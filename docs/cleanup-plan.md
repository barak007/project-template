One-argument fix; also drop the `= silentLogger` default once callers pass it. _Clear win, 5 min._

- [x] **A5. Fix the owner/admin cross-organization leak in `resolveWorkspaceRole`.** Found while writing A3/A4: the owner/admin shortcut in [policy.ts](../domain-server/services/policy.ts#L115) returns `"manager"` before verifying the workspace belongs to `organizationId`, and `listGrants`/`putGrant`/`removeGrant` then filter only on `workspaceId` — so an owner of org A can read, upsert, and delete grants on org B's workspaces through org A's routes (rule 3 violation; `setWorkspaceVisibility` is immune because its UPDATE filters on organizationId). Verify workspace-in-organization before the shortcut and add owner-path cross-org regression tests. _Security fix._
